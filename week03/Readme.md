Week 3: Variables, Data Types, Expressions and Input/Output

Objectives

- Understand variables and data types.
- Perform arithmetic operations.
- Use Scanner for input.
- Display formatted output.
- Compile and test Java programs.

Programs

- "week03/SimpleCalculator.java" — Performs arithmetic operations on two numbers.
- "week03/AverageCalculator.java" — Calculates the total and average of three scores.
- "week03/ItemCost.java" — Calculates the total cost using quantity and unit price.

How to Run

javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
